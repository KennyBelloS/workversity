# Plantillas de correo para Supabase

Se generan con `node supabase/email-templates/generar.mjs` (no las edites a mano: edita `api/_plantilla.js`).

Dónde se pegan: **Supabase → Authentication → Emails → Templates**.

| Archivo | Plantilla en Supabase | Asunto sugerido |
| --- | --- | --- |
| `recuperar-clave.html` | Reset Password | Tu enlace para entrar otra vez a Workversity |
| `confirmar-cuenta.html` | Confirm signup | Confirma tu correo y empieza a organizar tu semana |
| `enlace-magico.html` | Magic Link | Tu enlace de acceso a Workversity |
| `cambio-de-correo.html` | Change Email Address | Confirma tu correo nuevo en Workversity |
| `invitacion.html` | Invite user | Te invitaron a Workversity |
